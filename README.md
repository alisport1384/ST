# GoldPin

اپ اندروید و موتور بک‌تست استراتژی GoldPin. نسخهٔ این انتشار: **1.4.45 (versionCode 58)**.

## دادهٔ بک‌تست طلا (XAUUSD، M1)

در تنظیمات اپ، بازهٔ ۱، ۲، ۳ یا ۱۰ سال را انتخاب کنید؛ سپس همان دیتاست را دانلود و در نشست داخلی اجرا کنید. هر بازه فایل داده و نتیجهٔ بک‌تست جداگانه دارد:

- یک‌سال: ۳۵۱٬۸۹۴ کندل
- دوسال: ۷۰۱٬۰۶۷ کندل
- سه‌سال: ۱٬۰۴۰٬۷۳۰ کندل
- ده‌سال: ۳٬۴۰۲٬۱۲۶ کندل (از ۲۰۱۶-۰۸-۲۱ تا ۲۰۲۶-۰۸-۲۰؛ آخرین تاریخ موجود در منبع)

هیچ فایل دیتاستی داخل APK نیست؛ فایل انتخابی از مخزن به‌صورت جداگانه دانلود می‌شود. مشخصات، هش‌ها، منبع و روش بازتولید فایل‌ها در [`datasets/README.md`](datasets/README.md) آمده است. دادهٔ ده‌ساله در حافظه با آرایه‌های primitive فشرده نگه داشته می‌شود تا از مصرف چندصد مگابایتی آبجکت‌های Candle جلوگیری شود.
