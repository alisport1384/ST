# GoldPin

اپ اندروید و موتور بک‌تست استراتژی GoldPin. نسخهٔ کاری این تغییر: **1.4.43 (versionCode 56)**.

## دادهٔ بک‌تست طلا (XAUUSD، M1)

فایل‌های آمادهٔ دانلود در [`datasets/`](datasets/README.md) نگهداری می‌شوند:

- یک‌سال: ۳۵۱٬۸۹۴ کندل — این تنها بازه‌ای است که داخل اپِ بک‌تست قابل انتخاب است؛ فایل باید جداگانه از بخش تنظیمات دانلود شود.
- دوسال: ۷۰۱٬۰۶۷ کندل — فقط فایل دانلودی ریپو؛ به UI/اجرای داخلی اپ وصل نشده است.
- سه‌سال: ۱٬۰۴۰٬۷۳۰ کندل — فقط فایل دانلودی ریپو؛ به UI/اجرای داخلی اپ وصل نشده است.

هیچ فایل دیتاستی داخل APK نیست؛ نصب اپ سبک می‌ماند. مشخصات، هش‌ها، منبع و روش بازتولید فایل‌ها در [`datasets/README.md`](datasets/README.md) آمده است. راهنمای قدیمی بک‌تست برای توضیح معماری قبلی است و یادداشت به‌روزرسانی در ابتدای [`docs/RAHNAMA-YE-BACKTEST-DAKHELI.md`](docs/RAHNAMA-YE-BACKTEST-DAKHELI.md) به نسخهٔ فعلی ارجاع می‌دهد.
