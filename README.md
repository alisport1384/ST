# GoldPin

اپ اندروید و موتور بک‌تست استراتژی GoldPin. نسخهٔ این انتشار: **1.4.44 (versionCode 57)**.

## دادهٔ بک‌تست طلا (XAUUSD، M1)

در تنظیمات اپ، بازهٔ ۱، ۲ یا ۳ سال را انتخاب کنید؛ سپس همان دیتاست را دانلود و در نشست داخلی اجرا کنید. هر بازه فایل داده و نتیجهٔ بک‌تست جداگانه دارد:

- یک‌سال: ۳۵۱٬۸۹۴ کندل
- دوسال: ۷۰۱٬۰۶۷ کندل
- سه‌سال: ۱٬۰۴۰٬۷۳۰ کندل

هیچ فایل دیتاستی داخل APK نیست؛ فایل انتخابی از مخزن به‌صورت جداگانه دانلود می‌شود. مشخصات، هش‌ها، منبع و روش بازتولید فایل‌ها در [`datasets/README.md`](datasets/README.md) آمده است. راهنمای تفصیلی قدیمی بک‌تست برای توضیح معماری قبلی است؛ یادداشت ابتدای [`docs/RAHNAMA-YE-BACKTEST-DAKHELI.md`](docs/RAHNAMA-YE-BACKTEST-DAKHELI.md) وضعیت فعلی را خلاصه می‌کند.
