# GoldPin

اپ اندروید و موتور بک‌تست استراتژی GoldPin. نسخهٔ این انتشار: **1.4.46 (versionCode 59)**.

## دادهٔ بک‌تست طلا (XAUUSD، M1)

در تنظیمات اپ می‌توانید بازهٔ ۱، ۲، ۳، ۱۰ یا ۲۰ سال را انتخاب کنید؛ داده جداگانه دانلود می‌شود و سپس در نشست داخلی قابل اجراست. فایل داده و نتیجهٔ بک‌تست هر بازه مستقل‌اند.

- یک‌سال: ۳۵۱٬۸۹۴ کندل
- دوسال: ۷۰۱٬۰۶۷ کندل
- سه‌سال: ۱٬۰۴۰٬۷۳۰ کندل
- ده‌سال: ۳٬۴۰۲٬۱۲۶ کندل (۲۰۱۶-۰۸-۲۱ تا ۲۰۲۶-۰۸-۲۰)
- بیست‌سال: ۶٬۵۶۳٬۷۲۳ کندل (۲۰۰۶-۰۸-۲۱ تا ۲۰۲۶-۰۸-۲۰؛ آخرین تاریخ موجود در منبع)

هیچ دیتاستی داخل APK بسته‌بندی نشده است. دیتاست‌های ۱۰ و ۲۰ساله با آرایه‌های primitive فشرده پردازش می‌شوند تا از ساخت میلیون‌ها شیء `Candle` جلوگیری شود. بک‌تست ۲۰ساله ممکن است ده‌ها دقیقه طول بکشد و منابع حافظه و پردازندهٔ زیادی می‌خواهد؛ اپ پیش از دانلود/اجرا هشدار می‌دهد و روی دستگاه‌های کم‌حافظه ممکن است کامل نشود.

مشخصات، SHA-256، منبع، لینک‌ها و روش بازتولید فایل‌ها در [`datasets/README.md`](datasets/README.md) آمده است.
